# Agora

**Open-source, fully local multi-agent social simulation and prediction engine.**

Agora builds a knowledge graph from your documents, turns it into a population of
agents with personas and memory, lets them talk to each other on simulated Reddit,
X and WhatsApp-style groups, and writes a prediction report you can question.

Unlike pure LLM swarms, Agora also ships an analytics layer: real data seeds and
calibrates the simulation, backtests show how far to trust a prediction, and Monte
Carlo runs give ranges and probabilities instead of a single story.

- Runs fully offline on your own hardware (Ollama, llama.cpp, LM Studio, vLLM or any OpenAI-compatible server).
- Scales from an 8 GB laptop (overnight runs) to a GPU server.
- Projects are plain folders: zip, move, reopen.

> Status: early development (Phase 1: core simulation engine).
